# GPT-4o Geometry Results

This directory contains processed GPT-4o results for MATH Geometry subset.

## Performance

- **Training set**: 870 samples, Accuracy: 39.77%
- **Test set**: 509 samples, Accuracy: 41.13%

## Directory Structure

```
hendrycks_math_think_mGPT-4o_iNone/
└── geometry/
    ├── train/
    │   ├── tokens-1.json           # GPT-4o results (mentor-only format)
    │   └── gpt4o_evaluation.json   # Evaluation report
    └── test/
        ├── tokens-1.json           # GPT-4o results (mentor-only format)
        └── gpt4o_evaluation.json   # Evaluation report
```

## Data Format

Each `tokens-1.json` file contains a list of entries with:
- `question`: Problem statement
- `answer`: Ground truth answer (extracted from \boxed{})
- `generated`: Full GPT-4o output
- `predicted_answer`: GPT-4o's answer (extracted from \boxed{})
- `is_correct`: Whether the answer is correct
- `level`: Problem difficulty level
- `type`: "Geometry"

## Usage

### 1. Standalone Evaluation

To view GPT-4o's performance:
```bash
cat geometry/train/gpt4o_evaluation.json
cat geometry/test/gpt4o_evaluation.json
```

### 2. Cascade with Intern Model

To use GPT-4o as mentor in cascade:

```bash
# First, collect intern model results (e.g., DeepSeek-R1-Distill-Qwen-7B)
cd /mnt/data/zichuanfu/Ensemble-Hub/scripts/mentor_guided

# Option A: Copy from existing intern-only results
# If you have intern results at tokens0.json, copy them here:
cp existing_path/geometry/train/tokens0.json \
   /mnt/data/zichuanfu/Ensemble-Hub/data/acte_experiments/collected/hendrycks_math_think_mGPT-4o_iNone/geometry/train/

# Option B: Generate new cascade results with GPT-4o mentor
# Run collect_data_vllm_think.py with:
#   --mentor-model: Use GPT-4o via API (need to add GPT-4o support)
#   --intern-model: deepseek-ai/DeepSeek-R1-Distill-Qwen-7B
#   --token-levels: 0,100,500,1000
```

### 3. Train MLP Classifier

Once you have both mentor (tokens-1.json) and intern results (tokens0.json, tokens100.json, etc.):

```bash
cd /mnt/data/zichuanfu/Ensemble-Hub/scripts/mentor_guided

# Train on geometry train set
CUDA_VISIBLE_DEVICES=0,1,2,3,4,5,6,7 torchrun --nproc_per_node=8 train_mlp_classifier.py \
    --ddp \
    --data-dir /mnt/data/zichuanfu/Ensemble-Hub/data/acte_experiments/collected/hendrycks_math_think_mGPT-4o_iNone \
    --subset geometry \
    --pooling mean \
    --epochs 10 \
    --batch-size 32

# Evaluate on test set
# Results will be saved to geometry/mlp_model/results.json
```

### 4. Compare with Other Models

To compare GPT-4o (mentor-only) with other approaches:

```bash
python summarize_results.py \
    --data-dir /mnt/data/zichuanfu/Ensemble-Hub/data/acte_experiments/collected/hendrycks_math_think_mGPT-4o_iNone \
    --model-source individual
```
